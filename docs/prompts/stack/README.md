# Stack Prompts

This directory contains vendor or widely supported prompts and AI instructions for the project technology stack.

Before changing code related to a specific technology, read the corresponding file in this directory.

Examples:

- Redis cache: `cache/redis.md`
- CDC connectors (debezium): `cdc/debezium.md`
- Avro contracts: `contracts/avro.md`
- Avro validation: `contracts/avsc.md`
- Prisma schema or migrations: `database/prisma.md`
- PostgreSQL SQL/schema/indexes: `database/postgresql.md`
- NestJS code: `framework/nestjs.md`
- Node.js: `language/nodejs.md`
- Typescript: `language/typescript.md`
- Redpanda topics/producers/consumers: `messaging/redpanda.md`
- Redpanda Schema Registry: `messaging/redpanda-schema-registry.md`
- Nx workspace/project layout: `monorepo/nx.md`
- pnpm package manager: `monorepo/pnpm.md`
- TypeScript Project References: `monorepo/typescript-project-references.md`
- OpenTelemetry: `observability/opentelemetry.md`
- Pino logging: `observability/pino.md`
- Prometheus metrics: `observability/prometheus.md`
- Grafana dashboards: `observability/grafana.md`
- Tests: `testing/vitest.md`
- Testcontainers: `testing/testcontainers.md`
